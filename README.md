# 🗄️ Retail Sales & Orders Performance Analysis (SQL)



> Projet d'analyse commerciale et d'extraction de KPIs de vente à partir de données transactionnelles avec SQL.

---

## 🎯 Objectifs du Projet

Analyser la performance des ventes d'un distributeur multi-catégories pour répondre à des problématiques métier concrètes :
- Déterminer le chiffre d'affaires total et le panier moyen.
- Identifier les 10 produits générant le plus de revenus.
- Analyser la répartition géographique des ventes.
- Segmenter la taille des paniers d'achat à l'aide d'instructions conditionnelles.
- Filtrer les catégories motrices de l'entreprise.

---

##  Compétences SQL Utilisées

- **Agrégations et calculs statistiques :** `COUNT()`, `SUM()`, `AVG()`, `ROUND()`.
- **Regroupement et tri :** `GROUP BY`, `ORDER BY`, `LIMIT`.
- **Filtrage avancé sur données agrégées :** `HAVING`.
- **Segmentation conditionnelle métier :** `CASE WHEN ... THEN ... ELSE ... END`.
